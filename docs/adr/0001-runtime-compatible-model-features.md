# Use only runtime-compatible features in the deployed model

FIREWATCH DSS will train the deployed MVP model only on features the backend can produce at assessment time from a selected Turkish location, Forecast Window, calendar date, and Weather API Source response. Rich columns from the Morocco Wildfire Dataset such as raw Morocco coordinates, station metadata, lagged coordinates, NDVI, SoilMoisture, long historical aggregates, and 15-day lag features are treated as Training-Only Features unless a reliable Turkish runtime source is added, because honest live deployability is more important for the final-year MVP than maximizing proxy validation metrics. The selected Turkish location is still used for weather lookup, map placement, labels, and filtering; it is not fed directly into the deployed MVP model as raw coordinates.
